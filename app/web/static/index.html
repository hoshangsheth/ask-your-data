      How to use Ask Your Data

      1. Pick your data. The demo store is ready to go. To use your own file (CSV, Excel, JSON, PDF and more), sign in, then click Upload or drop the file anywhere.
      2. Ask in plain English. Type a question or tap one of the suggestions, e.g. “Top 5 products by revenue in 2025”.
      3. Chat about the data itself. Ask what it contains, what a column means or how a metric is defined; no SQL needed.
      4. Follow up. Say “same for 2024” or “break that down by city”: the chat remembers. New chat starts over.
      5. Check the answer. Switch between Chart, Table, SQL and How it worked.
      6. Export and rate. Download CSV, Excel, a chart image or a PDF report, and tell us with 👍 / 👎 if it helped.
